# Diagram sources

The `.svg` files are the illustrations embedded in the guides. Each has a matching editable `.excalidraw` scene with the same name. Open a scene in [Excalidraw](https://excalidraw.com/) to revise it, then update its SVG export before changing the guide.

The SVG lettering uses outlines from the [Patrick Hand](https://fonts.google.com/specimen/Patrick+Hand) handwriting font so it renders consistently in Markdown. Its Open Font License is included in `OFL-PatrickHand.txt`. The editable Excalidraw scenes use Excalidraw's handwriting font.
