# Brand assets

Provider and harness logos are sourced from [Lobe Icons](https://github.com/lobehub/lobe-icons), commit `79b551cf26aab9ea4ac701fb807160950a5b860f`, from `packages/static-svg/icons/*.svg`. The upstream MIT license is included in LICENSE.lobe-icons. Brand marks remain the property of their owners.

`catalog.json` is shared by Studio and offline reports. Monochrome SVGs use a fixed dark fill on a light tile and are embedded as data URIs, so viewing private reports never contacts a logo service. AnyBench and generic terminal symbols are local assets. Unknown endpoints receive the generic symbol; provider matches are exact API hosts.
